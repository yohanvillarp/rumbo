# Security Policy

## Supported Versions

The following table lists the versions of Rumbo currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Rumbo seriously. If you discover a security vulnerability or potential issue, please follow these guidelines:

1. **Do NOT disclose publicly**: Please do not open a public GitHub issue for security vulnerabilities.
2. **Contact Privately**: Send a private report to the maintainers at `security@nikelyh.tech` or open a private security advisory on GitHub.
3. **Information to Include**:
   - Description of the vulnerability.
   - Steps to reproduce the issue.
   - Potential impact.
   - Any suggested mitigations or fixes.

## Security Response Process

- **Acknowledgement**: We will acknowledge receipt of your report within 48 hours.
- **Assessment**: We will evaluate the vulnerability and determine the severity.
- **Resolution**: A patch will be developed, tested, and released promptly.
- **Public Disclosure**: After the fix is deployed, an advisory will be published acknowledging your disclosure.
